# Git 自动同步 Skill

## 触发
用户说"同步"、"拉代码"、"push"、"提交"、"推送"、"和另一台设备同步"

## 流程

### 开始工作前（拉取）
1. `git pull origin master --ff-only`
2. 如果有新代码 → 报告「✅ 拉到了 N 个新文件：[文件列表]」
3. 如果已是最新 → 报告「✅ 代码已是最新」
4. 如果网络失败 → 报告「⚠️ GitHub 连不上，稍后重试」

### 完成工作后（提交推送）
1. 先执行「开始工作前」的拉取步骤（避免冲突）
2. `git add -A`
3. `git commit -m "<类型>: <简短描述>"`
4. `git push origin master`
5. 报告「✅ 已推送：<提交信息>」

## 提交信息格式

```
feat: 添加[功能描述]
fix: 修复[问题描述]
refactor: 重构[模块描述]
style: 调整[UI描述]
docs: 更新[文档描述]
```

## 注意事项

- 提交前一定会先 pull，避免冲突
- 如果有冲突，先报告冲突文件，不要暴力覆盖
- 如果 push 失败（网络问题），提醒用户稍后手动 `git push`
