# Skill 生成器

## 触发
用户说"帮我做一个 [场景] 的 skill"、"我需要一个能自动 [任务] 的 skill"

## 流程
1. 问清楚：这个 skill 什么情况下触发？输入是什么？期望输出是什么？
2. 写一个 Markdown 文件到 `.claude/skills/[名称].md`
3. 文件包含三个部分：触发条件 + 执行步骤 + 输出格式
4. 告诉用户：以后你说「[触发词]」就会自动按这个流程走

## 模板
```markdown
# [Skill 名称]

## 触发
[什么情况下用这个 Skill]

## 流程
1. [步骤]
2. [步骤]

## 输出格式
[输出应该长什么样]
```
